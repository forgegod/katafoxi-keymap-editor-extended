Soft Off · firmware / hardware prerequisite

CONFIG_ZMK_PM_SOFT_OFF=y in the keyboard .conf; requires hardware power-off support. Wake-up depends on hardware (wake button or reset). Selection and Apply only stage source: no configuration changes, transport detection, reset, power-off, build, or flashing in the browser.
